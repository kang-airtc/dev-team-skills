# TechCorp 设计系统清单

## 颜色系统

| 名称 | 色值 | 用途 |
|------|------|------|
| 主色 Primary | `#2563EB` | 按钮、图标、CTA |
| 深色 Dark | `#0F172A` | 标题、Footer 背景 |
| Logo 色 | `#1E293B` | 品牌 Logo |
| 次要文字 | `#64748B` | 正文、描述 |
| 弱化文字 | `#94A3B8` | Footer 链接 |
| 白色 | `#FFFFFF` | 页面背景、按钮文字 |
| 浅灰背景 | `#F8FAFC` | 卡片背景、Hero 区 |

## 字体系统

全站统一使用 **Inter** 字体。

| 层级 | 字号 | 字重 | 用途 |
|------|------|------|------|
| Hero 标题 | 48px | 700 | 首屏大标题 |
| 区块标题 | 36px | 600 | 功能区块标题 |
| 卡片标题 | 20px | 600 | 卡片标题 |
| 正文 | 18px / 14px | normal | 描述性文字 |
| 按钮文字 | 16px | 500 | 按钮内文字 |
| 导航链接 | 14px | normal | 导航栏链接 |
| 版权信息 | 12px | normal | Footer 版权 |

## 组件库

### 导航栏 (Navbar)
- 高度：`64px`
- 背景色：`#FFFFFF`
- Padding：`24px` 水平，`48px` 垂直
- 布局：space-between，垂直居中

### 主要按钮 (Primary Button)
- 高度：`48px`
- 填充色：`#2563EB`
- 圆角：`8px`
- Padding：`16px` 水平，`32px` 垂直
- 文字：白色，`16px`，`fontWeight: 500`

### 描边按钮 (Outline Button)
- 高度：`48px`
- 填充色：透明
- 描边：`2px` 实线 `#2563EB`
- 圆角：`8px`
- Padding：`16px` 水平，`32px` 垂直
- 文字：`#2563EB`，`16px`，`fontWeight: 500`

### 小按钮 (Small Button)
- 高度：`40px`
- 填充色：`#2563EB`
- 圆角：`8px`
- Padding：`12px` 水平，`24px` 垂直
- 文字：白色，`14px`，`fontWeight: 500`

### 功能卡片 (Feature Card)
- 宽度：`340px`
- 背景色：`#F8FAFC`
- 圆角：`12px`
- Padding：`32px`
- 布局：垂直，`gap: 16px`

### Footer
- 背景色：`#0F172A`
- 布局：垂直，`gap: 24px`
- Padding：`48px`

## 间距与圆角

| 属性 | 值 | 用途 |
|------|------|------|
| 按钮圆角 | `8px` | 按钮、输入框 |
| 卡片圆角 | `12px` | 卡片、容器 |
| 小间距 | `12px`, `16px` | 内边距、间隙 |
| 中间距 | `24px`, `32px` | 卡片间隙、区块间距 |
| 大间距 | `48px`, `64px` | 页面内边距 |
| 超大间距 | `80px` | Hero 区垂直内边距 |

## 图标

| 属性 | 值 |
|------|------|
| 图标库 | Lucide |
| 尺寸 | `40px × 40px` |
| 颜色 | `#2563EB` |

## 整体风格

现代简洁的企业级 SaaS 风格，大量留白，清晰的视觉层次，蓝色为主色调的专业感设计。
