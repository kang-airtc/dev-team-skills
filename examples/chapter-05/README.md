# 第 05 章示例：公司站点设计阶段

本目录不随书附带固定产出物。设计阶段的产物（设计稿、评审报告、冲刺计划、规范检查、决策记录等）由你在项目里通过 **AI 对话 + design-\*** Skill 生成，文件名与路径按团队约定即可。

**场景约定**（与书稿第 5 章一致）：延续第 4 章的 **公司站点访客留言与咨询**，进入 **界面设计** 阶段，输入来自 `company-site-prd-reviewed.md`。

**路径**：design-* Skill 在仓库 **`.opencode/skills/`** 下。若需对齐书稿示例命名，可使用：

| 文件 | 对应 Skill | 说明 |
|---|---|---|
| `company-site-design.pen` | design-pencil | Pencil 设计稿（JSON 格式，支持 git 管理）|
| `company-site-decision.md` | design-discuss | 设计决策记录（含评估矩阵）|
| `company-site-sprint.md` | design-sprint | 设计冲刺计划（5 天版或压缩版）|
| `company-site-ui-check.md` | design-ui-check | UI 规范检查报告 |
| `company-site-review.md` | design-review | 多角色评审报告 |

**本目录已包含**：
- `company-site-design.pen`——随书提供的示例 Pencil 设计稿，可直接在 Pencil 中打开查看

在对话中说明当前任务、设计稿路径与期望输出文件名即可，由 AI 选择对应 Skill 并写入上述文件。
