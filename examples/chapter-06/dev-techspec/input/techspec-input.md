# 技术方案输入：新闻模块

## 基本信息

- 功能名称：新闻模块（News）
- 作者：笔者
- 日期：2026-04-27

## 背景

公司站点需要展示企业新闻动态，支持公开站展示和后台管理两个入口。

## 目标

1. 公开站支持新闻列表和详情页浏览
2. 后台支持新闻的新增、编辑、删除、发布/下架
3. 支持按发布时间排序，支持封面图和富文本正文

## 方案概述

前端 Next.js App Router 实现列表页（/news）和详情页（/news/{slug}），
后台在 /dashboard/news 下实现 CRUD 管理界面。
后端 FastAPI 提供 RESTful API（/api/news），使用 JWT 保护写操作。
数据库新建 news 表，Alembic 管理迁移。
