# 用户故事地图

> 来源 Skill：`req-storymap`  
> 视角：访客 / 编辑 / 管理员  
> 形式：Mermaid journey

```mermaid
journey
    title 访客浏览产品到留评论
    section 首页
      打开首页: 5: 访客
      看推荐产品: 4: 访客
    section 产品列表
      按分类筛选: 4: 访客
      翻页: 3: 访客
    section 产品详情
      看图集: 5: 访客
      看规格表: 4: 访客
      看历史评论: 4: 访客
      提交评论: 3: 访客
```

```mermaid
journey
    title 管理员维护产品
    section 登录
      访问 /login: 4: 管理员
      输入账号密码: 3: 管理员
      跳转 /dashboard: 5: 管理员
    section 新建产品
      点击"新建": 5: 管理员
      填表单 + 上传图集: 3: 管理员
      提交: 4: 管理员
    section 发布
      切换"上架"开关: 5: 管理员
      公开站校验: 5: 管理员
```

```mermaid
journey
    title 编辑发布新闻
    section 起草
      新建新闻: 4: 编辑
      写正文 + 配封面: 3: 编辑
    section 发布
      设置发布时间: 4: 编辑
      预览: 4: 编辑
      提交: 5: 编辑
```

## 关键关注点

- 访客路径里"提交评论"评分 3：因为多态字段在后台审核前不可见，访客体验上有等待感，需 UI 文案提示"评论已提交，审核后显示"。
- 管理员"填表单 + 上传图集"评分 3：图集上传单次最多 9 张，但 AI 生成的 UI 草稿未给出进度条；`design-ui-check` 已把它列入整改项。
