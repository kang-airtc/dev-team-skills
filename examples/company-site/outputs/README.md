# company-site / inputs

第 12 章「综合实战」按阶段沉淀的产出物。每个子目录对应一个阶段，文件名与
`SKILLS_PLAN.md` 中标注的产出位置一致。

```
outputs/
├── 01-req/         # 需求阶段（req-*）
├── 02-design/      # 设计阶段（design-*）
├── 03-dev/         # 开发阶段（dev-*）
├── 04-review/      # 评审阶段（review-*）
├── 05-test/        # 测试阶段（test-*）
├── 06-deploy/      # 发布阶段（deploy-*）
├── 07-monitor/     # 监控阶段（monitor-*）
├── 08-incident/    # 故障排查（incident-*）
└── bad-samples/    # 教学用反面教材（不可运行）
```

> 当前为骨架，每个阶段的产出物会在写第 12 章对应小节时填充。书稿正文里只引用
> 5–15 行片段，完整文件以本目录为准。
