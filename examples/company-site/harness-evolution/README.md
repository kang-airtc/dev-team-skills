# Harness Evolution 示例文件

第 14.11 节配套示例，展示 company-site 项目 Harness Engineering 的演进轨迹。

## 文件说明

| 文件 | 说明 |
|---|---|
| `incident-report.md` | 触发第一次 Ratchet 的事故复盘报告（incident-notification-001） |
| `AGENTS.md-v1` | 事故前的 AGENTS.md（Day 1 版本） |
| `AGENTS.md-v2` | 第一次 Ratchet 后的 AGENTS.md（新增环境变量规则） |
| `AGENTS.md-month3` | 第 90 天的成熟版 AGENTS.md（35 行，每条有来源注释） |

## 使用方式

对照书中 14.11 节阅读，重点关注每个版本之间的 diff——每一处变更都对应一次具体的事件或事故。
