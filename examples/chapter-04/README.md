# 第 04 章示例：公司站点需求（无预置产出物）

本目录**不再**随书附带一批固定的 Markdown/DSL 产出文件。需求阶段的典型产物（澄清稿、PRD、Backlog 等）由你在项目里通过 **Agent + `req-*` Skill** 自然语言驱动生成，文件名与路径按团队约定即可。

**场景约定**（与书稿第 4 章一致）：**企业官网 / 公司站点** 本迭代做 **「访客留言与咨询」** 相关能力。

**路径**：`req-*` Skill 在仓库 **`.opencode/skills/`** 下；若需对齐书稿示例命名，可使用：

- `company-site-clarified.md`（澄清）
- `company-site-prd.md` / `company-site-prd-reviewed.md`（PRD）
- `company-site-tasks.md`（Backlog）
- `company-site-storymap.md`（故事地图）
- `company-site-flow.dsl` / `company-site-flow.md`（流程图）
- `company-site-changes.md`（变更记录）

在对话中说明当前任务、附加上下文文件路径即可，由 Agent 选择对应 Skill 并写入上述文件。
