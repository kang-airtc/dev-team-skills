# 公司站点访客留言与咨询 产品需求文档
**版本**: v1.0  **日期**: 2026-04-27  **状态**: 草稿

## 1. 背景与目标

邮箱咨询渠道每日 100+ 垃圾邮件，客服处理成本高。本期目标：将正常咨询和垃圾内容分离，客服专注有效咨询。

## 2. 范围与边界

### 2.1 本期范围
- 访客提交留言（含联系方式、内容、来源页）
- 后台查看、回复、状态流转
- 内容审核员下架不当内容

### 2.2 Out of Scope
- 已登录客户身份打通（二期评估）
- 富文本与附件上传
- <待补充>：是否需要发送回复邮件给访客？

## 3. 用户与角色

| 角色 | 说明 |
|------|------|
| 访客 | 未登录，提交留言与联系方式 |
| 客服 / 运营 | 查看、回复、标记留言状态 |
| 内容审核员 | 下架不当内容（新增角色，权限待定） |

## 4. 功能详述

#### 4.1 访客留言提交
- 必填字段：姓名、联系方式、留言内容
- 提交即定稿，访客侧不支持编辑或撤回
- 同一访客 1 分钟内重复提交应被拦截

#### 4.2 客服后台
- 留言列表：按时间倒序，支持状态筛选
- 回复：客服可对留言发起回复，回复后状态自动流转为"已回复"
- 状态流转：待处理 → 处理中 → 已回复 → 已关闭

#### 4.3 内容审核与下架
- 审核员可将不当留言下架，下架后访客侧不可见
- 下架操作需记录操作人与时间

## 5. 非功能需求

### 5.1 性能
- 提交接口 P95 延迟 < 500ms（约定负载下）
- 列表查询 P95 延迟 < 1s

### 5.2 安全与合规
- <需产品确认>：留言中收集到的手机号、邮箱属于个人信息，是否需要法务介入审查存储与脱敏方式

## 6. 验收标准
- [ ] 访客端提交流程可用，重复提交有合理限制
- [ ] 后台列表与回复链路可用
- [ ] 内容安全与基础防刷按 PRD 实现
- [ ] 关键接口响应满足约定 SLA
