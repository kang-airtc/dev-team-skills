# 公司站点留言提交流程
**生成时间**: 2026-04-27  **来源**: company-site-prd.md §4.1  **整理人**: req-flowchart

## 主流程

```mermaid
flowchart TD
    n1([访客访问留言页]) --> n2[填写姓名/联系方式/留言内容]
    n2 --> n3{必填字段与格式校验通过?}
    n3 -->|是| n4[点击提交按钮]
    n3 -->|否| n5[高亮错误字段并提示]
    n5 --> n6([结束:字段错误])
    n4 --> n7{通过防刷限流?}
    n7 -->|是| n8[写入留言表,发送内部告警]
    n8 --> n9[跳转到提交成功页]
    n9 --> n10([结束:成功提交])
    n7 -->|否| n11[提示提交频率过快]
    n11 --> n12([结束:被限流])
```

## 流程说明
- DECISION 节点的判定逻辑详见 PRD 第 4 章功能详述
- "防刷限流" 的具体策略见 RC-001（验证码 + IP 限流）
