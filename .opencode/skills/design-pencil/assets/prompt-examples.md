# design-pencil prompt 示例

以下是传给 Pencil designer agent 的自然语言 prompt 参考。
不要在 prompt 里写颜色值、间距数值或 token 变量名——designer agent 会自己读取文档变量。

## 留言表单页

```
为公司官网设计一个访客留言表单页面，低保真线框图风格。
包含：页面标题"联系我们"、姓名输入字段、联系方式（邮件/电话）输入字段、
留言内容文本域（多行）、提交按钮。整体布局居中，移动端宽度。
```

## 登录页

```
设计一个企业内部系统的登录页，低保真线框图。
包含：产品 Logo 占位、邮箱输入框、密码输入框、登录按钮、"忘记密码"链接。
布局居中对齐，宽度适配桌面端。
```

## 个人中心页

```
设计移动端个人中心页面，低保真。
包含：顶部用户头像 + 昵称区域、菜单列表（我的订单/收货地址/设置）、
底部退出登录按钮。使用卡片式布局。
```

## spawn_agents 拆分示例

```python
spawn_agents({
  config: [
    {
      "prompt": "设计顶部导航栏：Logo 左侧，导航链接居中（首页/产品/关于/联系），桌面端宽度",
      "nodeIds": ["frame-nav"]
    },
    {
      "prompt": "设计留言表单区域：三个输入字段（姓名/联系方式/留言）+ 提交按钮，居中布局",
      "nodeIds": ["frame-form"]
    }
  ]
})
```
