# Summarize - 内容摘要

读完一份长文档或一个项目目录后，按统一格式输出一份"5 分钟读懂"版本的摘要。整个过程不需要任何脚本——Agent 用自带的文件读取工具拿到内容，按本文件描述的格式组织输出即可。

## 触发场景

- 接手一份陌生的设计文档/技术方案，想先快速建立全貌
- 拿到一个不熟悉的代码目录，想知道它大致在干什么
- 多人协作时，给团队成员一份结构统一的"内容速览"

## 工作流程

1. 判断输入是文件还是目录
   - 文件：直接读取全部内容
   - 目录：先读 `README.md`，再扫描主要源文件（不超过 5 个）
2. 按以下四个维度提炼信息：
   - **用途**：这份内容/这个项目要解决什么问题（一句话）
   - **核心要点**：3-5 条关键信息或主要功能
   - **关键依赖**：依赖的外部库/服务/上下游模块
   - **潜在问题**：模糊的表述、缺失的内容、可能的风险点
3. 按下方"输出格式"输出

## 输出格式

```markdown
## 摘要

**用途**：<一句话>

**核心要点**：
- 要点 1
- 要点 2
- ...

**关键依赖**：
- 依赖 A：用来做什么
- 依赖 B：用来做什么

**潜在问题**：
- 问题 1
- 问题 2
```

## 边界

- 不修改原文件，只输出摘要文本
- 不下"好/坏"的判断，只描述事实
- 长文档（超过 5000 行）不要硬塞所有内容，按章节抽样
