# 错误码字典

所有业务错误码的单一事实源。**新增错误码必须先在这里注册，再在代码里使用。**

## 0：成功

| code | msg | 说明 |
|------|-----|------|
| 0 | ok | 请求成功 |

## 1000-1999：通用错误

| code | msg | 触发场景 |
|------|-----|---------|
| 1001 | 参数缺失 | 必填参数没传 |
| 1002 | 参数格式错误 | 类型/格式不符（如邮箱格式不对） |
| 1003 | 参数取值非法 | 在合法范围之外（如 page < 0） |
| 1101 | 未登录 | 缺少 token 或 token 失效 |
| 1102 | 无权限 | 已登录但无操作权限 |
| 1103 | 签名验证失败 | 第三方回调验签不通过 |
| 1201 | 请求过于频繁 | 触发限流 |
| 1202 | 系统繁忙 | 上游依赖暂时不可用，可重试 |
| 1500 | 未知错误 | 兜底，仅在无法精确定位时使用 |

## 2000-2999：业务错误

| code | msg | 触发场景 |
|------|-----|---------|
| 2001 | 用户名已存在 | 注册时用户名冲突 |
| 2002 | 用户不存在 | 查询用户失败 |
| 2003 | 用户已被禁用 | 账号被禁用 |
| 2101 | 文章不存在 | 查询文章失败 |
| 2102 | 文章已被删除 | 文章软删后再被访问 |
| 2103 | 重复发布 | 短时间内提交相同内容 |
| 2201 | 评论不存在 | 评论被删除或不存在 |
| 2202 | 评论包含敏感词 | 内容审核未通过 |

## 命名约定

- code 数字本身不要表达"含义"——含义在 `msg` 字段里
- code 数字按"千位段 + 业务模块 + 序号"分配（如 2101 = 2xxx 业务段 + 1xx 文章模块 + 第 1 个错误）
- 同一类错误的码段保留 100 个空位，扩展时不会冲突
