# 默认设计系统规范

## 颜色（Color）

### 品牌色
- primary: #1890FF
- primary-hover: #40A9FF
- primary-active: #096DD9

### 功能色
- success: #52C41A
- warning: #FAAD14
- error: #F5222D
- info: #1890FF

### 文本色
- text-primary: #262626
- text-secondary: #595959
- text-hint: #8C8C8C
- text-disabled: #BFBFBF

### 边框与背景
- border: #D9D9D9
- border-split: #F0F0F0
- background: #F5F5F5
- background-white: #FFFFFF

## 字体大小（Font Size）

标准阶梯：
- xs: 12px（辅助文字、标签）
- sm: 14px（正文、按钮）
- base: 16px（标题、重要文字）
- lg: 20px（大标题）
- xl: 24px（页面标题）
- 2xl: 32px（特殊强调）

## 间距（Spacing）

基础单位：4px

- unit: 4px
- xs: 4px
- sm: 8px
- md: 16px
- lg: 24px
- xl: 32px
- 2xl: 48px

## 圆角（Border Radius）

- none: 0px（表格、卡片）
- sm: 4px（小按钮、标签）
- md: 8px（按钮、输入框）
- lg: 16px（大卡片、弹窗）
- full: 9999px（胶囊按钮）

## 阴影（Shadow）

- sm: 0 1px 2px rgba(0,0,0,0.05)
- md: 0 4px 12px rgba(0,0,0,0.1)
- lg: 0 8px 24px rgba(0,0,0,0.15)
