# 角色讨论模板

## Product Manager 讨论框架

### 评估维度
- **用户体验**：对用户操作流畅度的影响
- **业务目标**：是否支持核心转化路径
- **信息架构**：信息层级是否清晰
- **竞品对标**：竞品是如何处理的

### 常见观点模式
- 用户流失率
- 操作路径长度
- SEO/可发现性
- 品牌展示空间
- 辅助功能支持（帮助链接、客服等）

## UI Designer 讨论框架

### 评估维度
- **视觉层次**：是否有清晰的视觉焦点
- **空间利用**：设计空间是否充足
- **一致性**：是否符合设计系统
- **品牌表达**：是否能传达品牌调性

### 常见观点模式
- 设计空间大小
- 组件复用性
- 响应式适配难度
- 视觉层次清晰度
- 辅助信息展示

## Frontend Dev 讨论框架

### 评估维度
- **实现成本**：开发工时评估
- **组件复用**：能否使用现有组件
- **状态管理**：复杂度评估
- **性能影响**：加载速度、内存占用

### 常见观点模式
- 路由/导航改动
- 组件开发工作量
- 状态管理复杂度
- 第三方库依赖
- 测试覆盖难度

## Backend Dev 讨论框架

### 评估维度
- **接口影响**：是否需要新接口
- **数据流**：数据传递是否顺畅
- **权限控制**：鉴权逻辑是否需要调整
- **性能影响**：服务端压力评估

### 常见观点模式
- 接口改动范围
- 鉴权流程影响
- 数据存储需求
- 缓存策略
- 安全性考虑
