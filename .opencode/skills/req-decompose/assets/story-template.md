# 用户故事模板

本模板定义用户故事和任务的标准格式。

## 用户故事格式

```
### Story {编号}: {标题}

**作为** {角色}，
**我希望** {功能}，
**以便于** {价值}。

**优先级**: {P0/P1/P2}
**估算**: {story points}

**验收标准**：
- [ ] {条件1}
- [ ] {条件2}
- [ ] {条件3}

**依赖**: {依赖的故事或外部系统}
**备注**: {其他说明}
```

## 任务格式

```
#### Task {编号}: {标题}

- **类型**: {前端/后端/测试/设计/文档}
- **估算**: {hours}
- **负责人**: {姓名}
- **状态**: {待开始/进行中/已完成}
- **描述**: {详细描述}
- **关联 Story**: {Story 编号}
```

## Epic 格式

```
## Epic {编号}: {标题}

- **优先级**: {P0/P1/P2}
- **目标**: {一句话描述本 Epic 的目标}
- **估算**: {总 story points}
- **状态**: {待开始/进行中/已完成}
- **负责人**: {PO 或 Tech Lead}
```
