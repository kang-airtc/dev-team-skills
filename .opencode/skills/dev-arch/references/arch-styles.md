# 架构图样式说明

`dev-arch` 提供三种预设配色风格，对应不同的架构表达：

| 样式 | 填充色 | 边框色 | 适用场景 |
|------|--------|--------|---------|
| `layered` | 浅蓝 `#dae8fc` | 蓝 `#6c8ebf` | 分层架构（前端/后端/DB 三层） |
| `microservice` | 浅绿 `#d5e8d4` | 绿 `#82b366` | 微服务架构（多个独立服务并列） |
| `mvc` | 浅黄 `#fff2cc` | 黄 `#d6b656` | MVC 架构（M/V/C 三角关系） |

## 使用建议

- 同一项目里多张图保持同一种风格，便于横向对照
- 风格只是配色，不会影响布局——所有样式都是按 3 列网格自动排版
- 生成后用 draw.io Desktop 打开可以拖动、改色、改连线，源 XML 不会被破坏

## 输入格式参考

完整的输入示例：

```markdown
# 博客系统架构

## 组件
- frontend: Next.js 前端（用户交互）
- backend: FastAPI 后端（业务逻辑）
- db: PostgreSQL（主数据存储）
- cache: Redis（会话缓存）

## 依赖
- frontend -> backend
- backend -> db
- backend -> cache
```

注意：

- 组件描述（冒号后内容）可以省略，省略时用 id 作为标签
- 依赖必须用 ASCII 箭头 `->`，前后空格随意
- 同一组件被依赖多次时，会画多条箭头汇聚到这个节点
