# 设计评审检查清单

## UI Designer 检查项

### 视觉层次
- [ ] 页面有明确的视觉焦点
- [ ] 重要信息使用更大的字体或更重的字重
- [ ] 次要信息视觉层级正确

### 色彩规范
- [ ] 使用设计系统定义的颜色
- [ ] 对比度符合 WCAG AA 标准（4.5:1）
- [ ] 色彩语义一致（错误=红色、成功=绿色）

### 字体与排版
- [ ] 字体大小按阶梯使用（12/14/16/20/24/32）
- [ ] 行高合适（1.5-1.8倍）
- [ ] 文本对齐方式统一

### 间距与布局
- [ ] 间距为 4px/8px 的倍数
- [ ] 元素之间有清晰的呼吸空间
- [ ] 边缘对齐一致

## Frontend Dev 检查项

### 实现可行性
- [ ] 组件可在现有组件库中找到或容易封装
- [ ] 交互复杂度在合理范围内
- [ ] 响应式方案明确

### 性能考虑
- [ ] 图片资源有合理的尺寸和格式
- [ ] 动画效果不会影响性能
- [ ] 首屏加载内容可控

### 状态管理
- [ ] 表单状态清晰
- [ ] 错误状态有处理方案
- [ ] 加载状态有设计

## Product Manager 检查项

### 信息架构
- [ ] 信息层级符合用户认知
- [ ] 关键操作按钮位置合理
- [ ] 用户流程完整

### 文案
- [ ] 文案准确无歧义
- [ ] 错误提示友好
- [ ] 专业术语使用恰当

### 业务目标
- [ ] 设计支持业务目标
- [ ] 关键转化路径清晰
- [ ] 无冗余信息干扰

## Backend Dev 检查项

### 接口可行性
- [ ] 页面需要的接口在现有能力范围内
- [ ] 数据字段需求明确
- [ ] 分页/筛选逻辑清晰

### 权限与安全
- [ ] 敏感操作有权限控制
- [ ] 数据展示符合安全规范
- [ ] 表单提交有防重放机制
