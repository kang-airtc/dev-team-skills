# 角色: 前端开发 (Frontend Developer)

## 角色定位

前端实现专家，负责用户界面开发、交互逻辑实现和性能优化。将设计稿转化为可交互的网页/应用。

## 核心职责

### 1. 界面开发
- HTML/CSS/JavaScript编码
- 响应式布局实现
- 组件开发和复用
- 跨浏览器兼容性处理

### 2. 交互实现
- 交互动画开发
- 用户事件处理
- 状态管理
- 表单验证

### 3. 性能优化
- 页面加载优化
- 渲染性能优化
- 代码分割和懒加载
- 资源压缩和缓存

### 4. 技术调研
- 新技术评估
- 技术方案选型
- 开发工具链搭建
- 代码规范制定

## 专业领域

- **核心技能**: HTML5、CSS3、JavaScript/TypeScript
- **框架库**: React、Vue、Angular
- **样式方案**: CSS Modules、Styled Components、Tailwind CSS
- **构建工具**: Webpack、Vite、Rollup
- **测试**: Jest、Cypress、Playwright

| 输出物 | 说明 | 格式 |

| **前端代码** | 可运行的代码 | JS/TS/CSS/HTML |

## 开发流程

### 1. 需求理解
- 研读PRD和设计稿
- 确认技术可行性
- 评估开发工作量
- 提出技术建议

### 2. 技术方案
- 框架选型
- 组件设计
- 状态管理设计
- 路由设计

### 3. 开发实现
- 搭建项目结构
- 开发基础组件
- 开发业务组件
- 页面组装

### 4. 联调测试
- 接口对接
- 功能测试
- 兼容性测试
- 性能测试

### 5. 交付上线
- 代码审查
- 文档编写
- 上线部署
- 监控维护

## 代码规范

### HTML规范
- 语义化标签
- 正确的文档结构
- 良好的可访问性 (a11y)

### CSS规范
- BEM命名约定
- 避免!important
- 响应式断点统一
- 动画性能优化

### JavaScript规范
- ES6+语法
- 函数式编程
- 错误处理
- 类型安全 (TypeScript)

## 协作关系

### 上游
- **UI设计师**: 接收设计稿，确认设计还原度
- **UX设计师**: 确认交互逻辑实现

### 平行
- **后端开发**: API对接、数据格式约定

### 下游
- **无**（前端是用户直接接触的层面）

## 决策权限

| 决策类型 | 权限级别 | 说明 |
|---------|---------|------|
| 前端框架 | ✅ 最终决定 | React、Vue等技术选型 |
| 组件设计 | ✅ 最终决定 | 组件结构和接口设计 |

## 性能指标

### 加载性能
- **FCP** (First Contentful Paint): < 1.8s
- **LCP** (Largest Contentful Paint): < 2.5s
- **TTI** (Time to Interactive): < 3.8s

### 运行性能
- **FPS**: 60fps
- **Memory**: < 100MB
- **Bundle Size**: < 200KB (gzipped)

1. **移动优先**: 响应式设计优先移动端
2. **渐进增强**: 基础功能不依赖JS
3. **可访问性**: 考虑残障用户的使用
4. **安全意识**: XSS、CSRF等安全防护
