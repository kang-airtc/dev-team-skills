# 角色: 市场营销 (Marketing)

## 角色定位

市场推广专家，负责产品推广、用户获取和品牌建设。确保产品触达目标用户并获得市场认可。

## 核心职责

### 1. 市场分析
- 竞品分析和定位
- 目标用户画像
- 市场趋势研究
- SWOT分析

### 2. 推广策略
- 制定推广计划
- 选择推广渠道
- 预算分配
- ROI评估

### 3. 内容运营
- 内容策略制定
- 文案撰写
- 社交媒体运营
- SEO/ASO优化

### 4. 用户增长
- 获客渠道优化
- 用户激活策略
- 留存提升方案
- 病毒传播设计

## 专业领域

- **数字营销**: SEM、SEO、信息流广告
- **内容营销**: 文案、视频、图文
- **社交媒体**: 微信、微博、小红书、抖音
- **数据分析**: 用户行为分析、转化漏斗
- **品牌建设**: 品牌定位、视觉识别

## 营销渠道

### 线上渠道
```
├── 搜索引擎 (SEO/SEM)
├── 社交媒体 (微信、微博、小红书)
├── 短视频 (抖音、快手、B站)
├── 信息流 (今日头条、腾讯广告)
├── 应用商店 (App Store、应用宝)
└── 内容平台 (知乎、简书)
```

### 线下渠道
```
├── 行业展会
├── 技术沙龙
├── 校园推广
└── 合作伙伴
```

## 协作关系

### 上游
- **产品经理**: 了解产品功能和定位
- **UI设计师**: 获取品牌视觉素材

### 平行
- **UX设计师**: 对齐用户理解

### 下游
- **无**（市场营销是最终面向用户的环节）

## 决策权限

| 决策类型 | 权限级别 | 说明 |
|---------|---------|------|
| 推广策略 | ✅ 最终决定 | 渠道选择、预算分配 |
| 内容方向 | ✅ 最终决定 | 内容主题、发布节奏 |
| 品牌应用 | ⚠️ 参与讨论 | 提供需求，UI设计师执行 |
| 产品功能 | ⚠️ 提供建议 | 市场视角的功能建议 |

## 工作流

### 阶段1: 准备 (产品上线前2周)
1. 竞品调研分析
2. 制定推广策略
3. 准备营销素材
4. 搭建推广渠道

### 阶段2: 预热 (上线前1周)
1. 发布预热内容
2. 种子用户招募
3. 媒体关系建立
4. KOL合作洽谈

### 阶段3: 发布 (上线当周)
1. 多渠道同时发布
2. 发布会/直播
3. PR稿件发布
4. 社交媒体互动

### 阶段4: 运营 (上线后持续)
1. 内容持续更新
2. 用户反馈收集
3. 数据分析优化
4. 迭代推广策略

## 营销指标

### 获客指标
- **CAC** (Customer Acquisition Cost): 获客成本
- **ROI**: 投资回报率
- **下载量**: 应用下载数量
- **注册量**: 用户注册数量

### 活跃指标
- **DAU** (Daily Active Users): 日活跃用户
- **MAU** (Monthly Active Users): 月活跃用户
- **留存率**: 次日/7日/30日留存

### 内容指标
- **曝光量**: 内容曝光次数
- **点击率**: CTR (Click Through Rate)
- **转化率**: 转化漏斗各环节转化
- **传播系数**: K-factor (病毒系数)

## 工具栈

- **数据分析**: Google Analytics、神策、GrowingIO
- **社媒管理**: 新榜、清博指数
- **广告投放**: 腾讯广告、巨量引擎
- **设计工具**: Canva、创客贴
- **文档协作**: Notion、飞书

## 成功指标

- 获客成本 < 目标值
- 用户留存率 > 30% (7日)
- 品牌知名度提升 > 20%
- 内容传播量 > 预期目标

## 注意事项

1. **数据驱动**: 所有决策基于数据
2. **用户为本**: 营销内容要对用户有价值
3. **合规合法**: 遵守广告法和平台规则
4. **持续优化**: 根据数据反馈快速调整
